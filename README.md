# 🌸 ATELIER VERA — Fashion Storefront Website

A modern, responsive fashion store webpage for **ATELIER VERA**, designed with a soft blush-pink and royal lavender/plum aesthetic, editorial product photography, interactive filtering, and tactile shopping interactions.

## ✨ Key Features

* **Soft Rose-Blush & Lavender Palette:** Styled with blush-ivory surfaces, soft lavender-pink cards, deep velvet plum typography, and rose-berry & lavender accents.
* **Promotional Banner & One-Click Code Copy:** Top announcement bar featuring promo code **`VERA20`** (`20% off`) with instant copy feedback.
* **Editorial Hero & Featured Collections:** Showcases seasonal looks alongside curated collections (**The Rose Cashmere Edit**, **Lavender Tailoring**, and **Velvet Evening Capsule**).
* **Interactive Product Catalog:**
  * Filter by clothing category and sort products by price or featured order.
  * Displays product photography (static single-image display with no hover image swapping), regular/sale prices, color swatches, and size quick-pick (`XS–XL`).
  * Quick-view modal with fabric, fit, and styling details.
* **Wishlist & Slide-Over Shopping Bag:**
  * Save favorite pieces to a wishlist modal.
  * Slide-over bag drawer with item quantity controls, automatic knitwear bundle savings (`25% off 2+ knits`), `VERA20` promo code support, a `$250` complimentary shipping progress meter, and checkout flow.
* **Interactive Buttons & Newsletter Perks:** Click-ripple button feedback, morphing action states, and a newsletter signup that unlocks a `SALON15` welcome offer.

---

## 🛠️ Tech Stack

* **HTML5** — Semantic structure and modals/drawers
* **CSS3** — Custom properties (CSS variables), responsive Grid/Flexbox layouts, and button animations
* **JavaScript (ES6+)** — Filtering, sorting, wishlist & shopping bag state, promo/bundle calculations, and modals
